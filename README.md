# Carnet de batch cooking

Application du foyer pour le batch cooking du dimanche : planning des repas de la semaine, liste de courses à cocher à deux, catalogue des plats et historique des semaines.

- `index.html` : l'application (une seule page). Les plats, menus et listes de courses sont dans le bloc `carnet-data` du fichier, mis à jour à chaque semaine validée.
- Les cases cochées, le planning des repas, les avis et les réglages sont dans Firebase (Firestore), partagés en direct.

Hébergée avec GitHub Pages (branche `main`, dossier racine).
